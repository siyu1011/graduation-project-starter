# 随仓库使用的项目级技能

两个完整技能位于项目根目录 `.agents/skills/`，无需安装到个人目录。保留隐藏目录，在此项目打开 Codex 会话即可发现；既有会话未显示时重新加载会话。

```text
.agents/skills/
├─ graduation-report/     毕业报告、图表规划、真实截图、格式核对
└─ diagram-design/        架构、流程、功能模块、E-R、状态等图表
```

调用示例：

```text
$graduation-report 根据当前项目和我提供的学校模板生成毕业设计报告，先核对实际功能；图表使用项目内 diagram-design。
```

```text
$diagram-design 绘制当前系统架构图，白底黑字，保留 HTML/SVG 图源及论文插图。
```

也可明确要求读取 `.agents/skills/技能名/SKILL.md`。根目录 AGENTS.md 已登记入口。复制底座或制作源码包时保留两个完整文件夹及 references、assets、scripts，不要只复制入口文件。

## 环境与模板

技能文件提供工作流程、参考和脚本，不自带模型服务、Word/PDF 渲染引擎或浏览器自动化能力。Word 排版与渲染、真实运行截图、PNG 导出需要对应运行环境；缺失时如实记录未验证项。

报告技能附带洛阳职业技术学院格式参考，只有当前用户明确采用时才使用，其他学校按自己的模板执行。示例信息不得当作当前学生资料，未实现功能不能写成成果。

## 来源与更新

- graduation-report：从实际软件毕业设计工作流整理，覆盖项目事实、报告、图表、真实截图、文献、渲染及定稿保护，已移除默认绑定来源项目学校的口径。
- diagram-design：来自 cathrynlavery/diagram-design 已安装版本 2.6.103 的完整技能目录，附 MIT LICENSE；保留上游参考与导出脚本。此目录不是完整插件安装，也不会自动随上游更新。
- 更新日期：2026-10-17。上游或个人技能更新不会自动覆盖仓库副本，更新时同时核对配套资源和相对引用。
- 技能不包含数据库配置；是否将实际凭据加入私人包必须由各项目用户单独授权，公开仓库和普通源码包只包含配置示例。
